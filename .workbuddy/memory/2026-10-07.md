## noice cmdline / 搜索框居中

用户要 "cmdline 和搜索框居中"。

**关键坑**：noice 默认 `cmdline.view = "cmdline_popup"`（本来就是居中弹窗），
但 LazyVim 默认启用 `presets.bottom_search = true`，而该预设把
`search_down` / `search_up` 的 `view` 强制改成 `"cmdline"`（底部长条）。
结果：`/` `?` 搜索框退回底部、不居中；`:` 命令框却是居中的 —— 两边不一致。

**修法**（`lua/plugins/noice.lua`）：
```lua
opts = {
  presets = { bottom_search = false },   -- 关掉，搜索框回到居中的 cmdline_popup
  cmdline = { view = "cmdline_popup" },  -- `:` 也显式指过去（保险）
  views = { cmdline_popup = { relative = "editor",
    position = { row = "50%", col = "50%" },  -- nui 百分比定位 = (容器-窗口)*比例 = 真正居中
    size = { min_width = 60, width = "auto", max_width = 120, height = "auto" },
    border = { style = "rounded", padding = { 0, 1 } } } },
}
```
注：`cmdline.view` 是所有 cmdline kind（cmdline/search_down/search_up）的默认视图
（见 noice config/cmdline.lua:31 `view = Config.options.cmdline.view`），所以设一处即可。

验证难点：headless 里 `require("noice.config").options` 在 setup 前是空的
（`.options` 只在 setup 后填充），探针读不到；直接靠源码 + 启动 0 报错确认即可。

## blink cmdline `:mess` 空弹窗（已修）

**现象**：`:mess` 弹出空菜单（之前还误报过 `cmdline → fuzzy Unexpected field`）。
**根因**：blink 的 cmdline 模式默认 `menu.auto_show = function(ctx) return ctx.mode == 'cmdwin' end`
（见 `blink.cmp/lua/blink/cmp/config/modes/cmdline.lua:12`）。普通 `:` 命令 `ctx.mode == 'cmdline'`
（不是 'cmdwin'），所以默认 `auto_show` 恒为 false —— `:` 命令补全菜单永不自动弹出 → 空弹窗。
我之前把判断改成 `getcmdtype()==":"` 也失败（noice 居中弹窗上下文里偶发返回空）。
**修法**（`lua/plugins/blink-cmp.lua` cmdline 块）：
```lua
completion = { menu = { auto_show = true,  -- 强制 true，: 命令正常弹菜单
  draw = { columns = { { "label", "label_description", gap = 1 } } } } }  -- 去掉 Property 列
```
另：`fuzzy` 不是 per-mode 合法字段（排序只能全局配），之前的 `cmdline.fuzzy` 会报
"Unexpected field" —— 已删。
**验证**：隔离 headless 测（`-u` 指向配置目录内的临时 init，因为沙箱 /tmp 不可读）确认
`config.cmdline.completion.menu.auto_show == true`、SOURCES=`{cmdline}`、UP bound、无报错、exit 0。
注：`config.modes` 在运行时是 nil，解析后的模式配置在 `require("blink.cmp.config").cmdline`（metatable 代理到内部 `config`）。
